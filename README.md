# BEAN.exe — Software Engineering Portfolio

A cinematic, interactive developer portfolio that blends creative visual design with software engineering.

**BEAN.exe** showcases my development journey, technical skills, education, and projects through a unique, dark-themed interface inspired by a futuristic developer workspace.

## ✨ Features

- Interactive sidebar navigation
- Cinematic hero section with animated visual effects
- About me and education sections
- Project showcase with interactive elements
- Categorized technical skills
- Interactive terminal-style lab
- Responsive layout and motion effects
- Contact section

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Responsive Web Design
- CSS Animations and Transitions
- GitHub Pages
